# HUSTLE CITY — v1 Food Stand

Open `index.html` in a browser. No server, backend, database, or external assets are required.

Core loop implemented:
Start → choose Food Stand → move → customer → cook → serve → earn → restock → upgrade/hire → day progression → save.

Controls:
- Desktop: WASD / Arrow keys
- Mobile: virtual joystick + INTERACT
- Menu: upgrades, staff, supplier, save/reset

Save data uses localStorage under `hustleCity`.
